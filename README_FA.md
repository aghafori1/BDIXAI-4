# BDIX AI — Clean Production Baseline

این پوشه **نسخهٔ فعلی و فعال** پروژه است؛ فقط فایل‌هایی که برای اجرای همین نسخه لازم‌اند نگه داشته شده‌اند.

## اجرا

- `index.html` — صفحه اصلی
- `contact.html` — صفحه تماس
- بدون build step، package manager یا dependency خارجی
- برای اجرای محلی، `index.html` را در مرورگر باز کنید.

## زبان‌ها

- عربی: `?lang=ar`
- انگلیسی: `?lang=en`
- فارسی: `?lang=fa`

## ساختار فعال

- HTML: `index.html`, `contact.html`
- CSS: فایل‌های فعال مرتبط با Home و Contact
- JS: فایل‌های فعال مرتبط با navigation، hero، cinema، portfolio، background و contact
- برند: `assets/brand/`
- فونت‌ها: `fonts/`
- مجوز فونت‌ها: `licenses/fonts/`

## وضعیت فعلی

- سایت Static و framework-free است.
- کارت‌های خدمات، مفهوم‌ها، فرایند و اصول به‌شکل grid ساده و واکنش‌گرا نمایش داده می‌شوند؛ حالت fan/slider کارت‌ها و برچسب‌های بالای آن‌ها حذف شده‌اند.
- سه‌زبانه و RTL/LTR است.
- فرم Contact فعلاً Prototype است و داده‌ای ارسال یا ذخیره نمی‌کند.
- Portfolio شامل Conceptهاست و نباید بدون تأیید مالک به‌عنوان Case Study واقعی معرفی شود.
- نسخه‌های قدیمی و فایل‌های snapshot در این baseline نگهداری نمی‌شوند؛ تاریخچه باید در Git نگهداری شود.

## قانون نگهداری

**هیچ فایل نسخه‌دار، backup، snapshot یا handoff تکراری ایجاد نکنید.** فایل فعلی را درجا ویرایش کنید.

تنها سند وضعیت پروژه: `PROJECT-HANDOFF.md`

پس از هر تغییر، همین فایل درجا به‌روزرسانی شود.
