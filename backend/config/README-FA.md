# راه‌اندازی بک‌اند BDIX AI (Django)

این پوشه یک API واقعی برای فرم تماس می‌سازد: درخواست را در پایگاه داده ذخیره می‌کند، آیدی اینستاگرام را به لینک کامل `https://www.instagram.com/{username}/` تبدیل می‌کند و در صورت تنظیم Resend، اعلان ایمیلی می‌فرستد.

> این ZIP فایل پایگاه داده یا کلیدهای محرمانه ندارد. برای استفادهٔ عمومی، کلیدها را فقط در Environment Variables میزبان وارد کنید.

## اجرای محلی در Windows PowerShell

از مسیر `BDIX-AI-CLEAN-BASELINE\backend\config` اجرا کنید:

```powershell
py -m venv ..\..\.venv
..\..\.venv\Scripts\python.exe -m pip install -r requirements.txt
..\..\.venv\Scripts\python.exe manage.py migrate
..\..\.venv\Scripts\python.exe manage.py createsuperuser
..\..\.venv\Scripts\python.exe manage.py runserver
```

اگر `.venv` در ریشهٔ پروژه از قبل ساخته شده، فرمان ساخت محیط مجازی را رد کنید. سپس سایت را در `http://127.0.0.1:8000/` ببینید. این روش، سایت و API را روی یک origin اجرا می‌کند؛ دیگر لازم نیست `py -m http.server 5500` را جداگانه اجرا کنید.

- فرم: `/contact.html?lang=fa`
- مدیر Django: `/admin/`
- بررسی سلامت: `/api/health/`
- ارسال فرم: `POST /api/contact/` با JSON
- پایگاه‌دادهٔ محلی: SQLite در `backend/config/db.sqlite3`؛ فایل موجود را پاک نکنید.

## اعلان ایمیلی

ارسال ایمیل از طریق API HTTPS سرویس Resend انجام می‌شود، نه SMTP. در Resend حساب بسازید، دامنه‌ای را که کنترل می‌کنید تأیید کنید و API key بسازید. سپس این متغیرها را در محیط محلی یا پنل میزبان تنظیم کنید:

- `RESEND_API_KEY` — محرمانه؛ در چت یا کد قرار ندهید.
- `DEFAULT_FROM_EMAIL` — فرستنده‌ای روی دامنهٔ تأییدشده، مثل `notifications@yourdomain.com`.
- `ADMIN_NOTIFICATION_EMAIL` — نشانی‌ای که باید درخواست‌های جدید را دریافت کند.

برای تست محلی، این مقادیر را در همان PowerShell و پیش از اجرای `runserver` وارد کنید؛ مقدارها را در چت یا مخزن عمومی نفرستید:

```powershell
$env:ADMIN_NOTIFICATION_EMAIL="نشانی دریافت اعلان"
$env:DEFAULT_FROM_EMAIL="notifications@دامنه-تأییدشده-شما"
$env:RESEND_API_KEY="کلید Resend شما"
```

اگر سرویس ایمیل هنوز تنظیم نشده باشد، درخواست همچنان در دیتابیس ذخیره می‌شود اما اعلان ایمیل ارسال نخواهد شد؛ وضعیت در log سرویس ثبت می‌شود.

## مشاهدهٔ درخواست‌ها

در `/admin/` وارد شوید؛ فهرست درخواست‌ها شامل نام، ایمیل، کشور، نوع کسب‌وکار، لینک Instagram و زمان ثبت است. لینک پروفایل از پنل قابل بازکردن است.

### ساخت مدیر در Render Free

Render Free ممکن است دسترسی Shell نداشته باشد. پیش از اولین deploy (یا پیش از یک redeploy اولیه)، در Environment Variables این سه مقدار را تنظیم کنید: `DJANGO_SUPERUSER_USERNAME`, `DJANGO_SUPERUSER_EMAIL`, `DJANGO_SUPERUSER_PASSWORD`. فرمان build مدیر را فقط در صورت نبود همان نام کاربری می‌سازد و رمز کاربر موجود را تغییر نمی‌دهد. پس از ساخت موفق مدیر، متغیر رمز را فوراً حذف کنید.

## آنلاین‌کردن آزمایشی با Render

1. پروژه را در یک مخزن خصوصی GitHub قرار دهید؛ `.venv`, `db.sqlite3`, کلیدها و `.env` را commit نکنید.
2. در Render، یک **Blueprint** از مخزن بسازید. فایل `render.yaml` در ریشه، یک سرویس Django و PostgreSQL آزمایشی می‌سازد.
3. قبل از deploy مقادیر Resend و سه متغیر مدیر را در بخش Environment تنظیم کنید؛ برای مدیر از رمز قوی و منحصربه‌فرد استفاده کنید.
4. بعد از deploy، دامنهٔ `onrender.com` را باز کنید، فرم را ارسال کنید و `/admin/` را بررسی کنید.
5. اگر اعلان ایمیلی کار نکرد، پنل Resend را برای تأیید دامنه و log سرویس را برای خطا بررسی کنید.

سرویس وب Render را طوری پیکربندی کرده‌ایم که صفحات سایت و API از همان دامنه ارائه شوند؛ بنابراین CORS جداگانه لازم نیست. در صورت انتقال فرانت‌اند به میزبان/دامنهٔ دیگر، باید origin دقیق آن را به allowlist در `FORM_ALLOWED_ORIGINS` اضافه کنیم.

### مهم دربارهٔ پلن رایگان

پلن رایگان برای پیش‌نمایش و آزمایش است، نه انتشار تجاری: سرویس وب پس از ۱۵ دقیقه بی‌درخواستی خاموش می‌شود و درخواست اول پس از خاموشی ممکن است حدود یک دقیقه برای بیدارشدن زمان ببرد. فایل‌سیستم محلی ماندگار نیست؛ به همین دلیل از PostgreSQL استفاده می‌کنیم. دیتابیس رایگان Render طبق مستند فعلی ۳۰ روز پس از ایجاد منقضی می‌شود و پس از grace period داده‌ها حذف می‌شوند؛ قبل از آن باید به پلن پولی ارتقا دهید یا از داده‌ها نسخهٔ پشتیبان امن بگیرید.

## نکات امنیت و انتشار

- `DEBUG=false`, کلید محرمانه، دامنه‌های مجاز و پایگاه‌دادهٔ محیط تولید را فقط در تنظیمات میزبان قرار دهید.
- فایل `db.sqlite3` محلی را برای انتقال آنلاین استفاده نکنید؛ Render PostgreSQL جداگانه است.
- endpoint فرم عمومی است و برای آن honeypot، محدودیت سادهٔ تعداد درخواست و اعتبارسنجی سمت سرور در نظر گرفته شده؛ پیش از تبلیغ عمومی/ترافیک بالا، CAPTCHA/ضداسپم و مانیتورینگ اضافه کنید.
- بررسی اینستاگرام فقط قالب نام کاربری را می‌سنجد؛ API رسمی برای تأیید وجود یا مالکیت حساب وصل نشده است.
- ایمیل اعلان به معنی تأیید تحویل نهایی یا پاسخ‌گویی خودکار به مشتری نیست.
